# ST HR — ລະບົບບຸກຄະລາກອນ

ແອັບ HR ແຍກຈາກ ST POS: ສະແກນໜ້າ + GPS ລົງເວລາ, ລາພັກ, ເບີກລ່ວງໜ້າ, ເງິນເດືອນ, audit log.
ຕອນນີ້ເປັນ **ໂໝດສາທິດ**: ຂໍ້ມູນເກັບໃນ browser ຂອງເຄື່ອງທີ່ເປີດເທົ່ານັ້ນ (localStorage).

## ແລ່ນໃນເຄື່ອງ

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # ທົດສອບໂຕຄິດໄລ່ເງິນເດືອນ, ມາຊ້າ, ລາພັກ, ການອະນຸມັດ
npm run build    # ໄດ້ໂຟນເດີ dist/
```

ກ້ອງ ແລະ GPS ຕ້ອງໃຊ້ HTTPS (ຫຼື localhost). ລອງໃນມືຖືແທ້ຜ່ານລິ້ງ GitHub Pages.

## ລອງແຕ່ລະບົດບາດ

ໜ້າທຳອິດເລືອກ "ເຂົ້າໃຊ້ເປັນ":

| ຜູ້ໃຊ້ | ບົດບາດ | ລອງຫຍັງ |
|---|---|---|
| ຄຳຫຼ້າ, ບຸນມີ, … | ພະນັກງານ | ລົງທະບຽນໜ້າ → ກົດປຸ່ມໃຫຍ່ → ສະແກນ; ຂໍລາ; ເບີກເງິນ |
| ສົມພອນ | ຫົວໜ້າ | ກວດການລົງເວລາ "ລໍກວດ", ອະນຸມັດລາ, ສັ່ງ OT |
| ແສງດາວ | ບັນຊີ | ກະກຽມເງິນເດືອນ, Export |
| Admin | ເຈົ້າຂອງ / HR | ອະນຸມັດ & ລັອກງວດ, ຕັ້ງຄ່າ, Audit log |

ຕັ້ງຄ່າ → ສາຂາ → **"ໃຊ້ຕຳແໜ່ງຂ້ອຍຕອນນີ້"** ເພື່ອໃຫ້ GPS ຜ່ານຕອນທົດລອງ.
- **ເຂົ້າຄອມ = ເຂົ້າໜ້າບໍລິຫານເລີຍ**: ໜ້າຈໍກວ້າງ ≥ 900px (ຄອມ/ແທັບເລັດແນວນອນ) ຄົນທີ່ມີບົດບາດ Admin/ຫົວໜ້າ/ບັນຊີ/ຜູ້ກວດສອບ ເຂົ້າໜ້າບໍລິຫານ HR ທັນທີ; ໃນມືຖືຍັງເປີດໜ້າລົງເວລາກ່ອນ ແລະ ເຂົ້າໜ້າບໍລິຫານຈາກເມນູ. ກົດ "‹ ກັບໜ້າລົງເວລາ" ເພື່ອສະຫຼັບໄດ້ທຸກເວລາ.
- **ກົດເກນບໍລິສັດ & ຕັ້ງຄ່າ** (Admin): ແຖບ ສະຫຼຸບກົດເກນ (ອ່ານເປັນປະໂຫຍກ + ປຸ່ມແກ້ໄຂ) · ສາຂາ & GPS · ກະວຽກ · ເວລາ & ສະແກນ · ລາພັກ & ອະນຸມັດ · ວັນພັກ · ເງິນເດືອນ & ອາກອນ · ແພັກເກັດ · **ປະຫວັດການແກ້** (ໃຜແກ້ຫຍັງ ເມື່ອໃດ ຄ່າເກົ່າ → ຄ່າໃໝ່). ແຕ່ລະກົດເກນມີຄຳອະທິບາຍສັ້ນໆ; ຜູ້ກວດສອບເບິ່ງໄດ້ຢ່າງດຽວ.

## ໂຄງສ້າງ

```
src/domain/   ກົດລະບຽບທຸລະກິດ (pure functions + tests) — ບໍ່ຂຶ້ນກັບ UI ຫຼື storage
src/data/     DataStore: LocalStore (ສາທິດ) / ApiStore (server ຈິງ, ໃຊ້ interface ດຽວກັນ)
src/device/   ກ້ອງ + ຈື່ໜ້າ (@vladmandic/face-api, models ຢູ່ public/models), GPS
src/ui/       ໜ້າຈໍພະນັກງານ (ມືຖື) ແລະ ໜ້າຈໍຫົວໜ້າ / HR
```

## Export ລາຍງານເຂົ້າ-ອອກ (Excel)

ໜ້າ **ລາຍງານ** (ພະນັກງານ) ແລະ **ລາຍງານທີມ** (ຫົວໜ້າ/ບັນຊີ/ເຈົ້າຂອງ/ຜູ້ກວດສອບ) ມີປຸ່ມດາວໂຫຼດ .xlsx 3 sheet: ສະຫຼຸບ, ລາຍລະອຽດລາຍມື້, ຂໍ້ມູນລາຍງານ. ຕົວເລກໃນໜ້າຈໍ ແລະ ໄຟລ໌ມາຈາກຕົວຄິດດຽວກັນ. ຫົວໜ້າໄດ້ສະເພາະພະແນກທີ່ດູແລ. ທຸກການ export ຖືກບັນທຶກໃນ audit log.

## ການຈັດການພະນັກງານ, ກະ ແລະ ເງິນເດືອນ

- **ເພີ່ມ / ປິດບັນຊີພະນັກງານ** (ພະນັກງານ → "+ ເພີ່ມພະນັກງານ" ແລະ ແກ້ໄຂ → ລາອອກ): ໃຊ້ການກວດ 2 ຄົນຄືກັບເງິນເດືອນ. ບົດບາດເລີ່ມເປັນ "ພະນັກງານ" ສະເໝີ. ເດືອນທີ່ເຂົ້າ / ອອກ ຄິດເງິນເດືອນຕາມສັດສ່ວນວັນ (OT ແລະ ລາບໍ່ຮັບເງິນໃຊ້ເງິນເດືອນເຕັມຄິດອັດຕາ). ຄົນທີ່ອອກແລ້ວບໍ່ຢູ່ໃນລາຍຊື່ login, ເງິນເດືອນ ແລະ ລາຍງານຂອງເດືອນຖັດໄປ; ປະຫວັດຍັງຢູ່ຄົບ.
- **ເພີ່ມສາຂາ** (ຕັ້ງຄ່າ → ສາຂາ & GPS): ກວດພິກັດ ແລະ ລັດສະໝີ 10–2000 ມ. ຍັງບໍ່ມີການລຶບສາຂາ (ກັນສະແກນເກົ່າຊີ້ໄປຫາສາຂາທີ່ບໍ່ມີ).
- **ສະລິບເງິນເດືອນ**: ພະນັກງານພິມ / ບັນທຶກ PDF ໄດ້ເອງ; ບັນຊີ / ເຈົ້າຂອງ ເປີດສະລິບຂອງແຕ່ລະຄົນຈາກໜ້າເງິນເດືອນ. ງວດທີ່ຍັງບໍ່ລັອກຖືກໝາຍວ່າ "ຕົວເລກປະມານການ". **Export Excel** ຂອງງວດ (ແຕ່ລະຄົນ + ແຖວລວມ + sheet ຂໍ້ມູນງວດ) ຖືກບັນທຶກໃນ audit log.
- **ລືມລົງເວລາອອກ**: ເຂົ້າແລ້ວແຕ່ບໍ່ອອກ ຫຼັງກະເລີກ + 60 ນທ → ໝາຍ "ລືມລົງເວລາອອກ" ໃນລາຍງານ (ມີຖັນນັບມື້), ແຈ້ງເຕືອນພະນັກງານ ແລະ ຫົວໜ້າພະແນກ (ຄັ້ງດຽວຕໍ່ຄົນຕໍ່ມື້), ແລະ ມີແຖບໃນໜ້າລົງເວລາໃຫ້ກົດຂໍແກ້ເວລາອອກ. ຍ້ອນຫຼັງ 7 ມື້.
- **ກະຂ້າມຄືນ**: ກະທີ່ເວລາເລີກນ້ອຍກວ່າເວລາເລີ່ມ (22:00 → 06:00, ຍາວສຸດ 16 ຊມ.). ການລົງເວລາຫຼັງທ່ຽງຄືນນັບເປັນມື້ທີ່ເລີ່ມກະ. ອອກວຽກຊ້າກວ່າກະເລີກໄດ້ເຖິງ 4 ຊມ. (OT); ຫຼັງນັ້ນຕ້ອງຂໍແກ້ເວລາ. ຂໍ້ຈຳກັດ: ຖ້າເຂົ້າວຽກກະກາງຄືນຫຼັງທ່ຽງຄືນ ລະບົບນັບເປັນມື້ໃໝ່.

- **ກະຢືດຢຸ່ນ (ພະນັກງານອອຟຟິດ ບໍ່ກຳນົດເວລາ)**: ຕັ້ງຄ່າ → ກະວຽກ → "+ ເພີ່ມກະຢືດຢຸ່ນ" ແລ້ວກຳນົດຊົ່ວໂມງຕໍ່ມື້ (ເຊັ່ນ 8). ເຂົ້າ-ອອກເວລາໃດກໍໄດ້, ບໍ່ຄິດມາຊ້າ; ວັນພັກປະຈຳອາທິດ ແລະ ວັນພັກລັດຖະການຍັງໃຊ້; ມື້ທີ່ເຮັດຕ່ຳກວ່າຊົ່ວໂມງທີ່ກຳນົດ ມີໝາຍເຫດໃນລາຍງານ (ບໍ່ຫັກເງິນ). ລືມລົງເວລາອອກ ຈະແຈ້ງຫຼັງສິ້ນມື້. ບໍລິສັດໃໝ່ມີກະນີ້ໃຫ້ເລີຍ.
- **ລາເຄິ່ງວັນ / ເປັນຊົ່ວໂມງ**: ເລືອກເຄິ່ງວັນເຊົ້າ / ບ່າຍ ຫຼື ຈຳນວນຊົ່ວໂມງ (ເຄິ່ງຊົ່ວໂມງເປັນຂັ້ນ) ໃນມື້ດຽວ. ນັບເປັນມື້ຕາມຊົ່ວໂມງເຮັດວຽກຂອງກະຕົນເອງ (7.5 ຊມ → 3 ຊມ = 0.4 ມື້). ກວດການລາທັບຊ້ອນ ແລະ ລາລວມບໍ່ເກີນ 1 ມື້. ລາເຊົ້າທີ່ອະນຸມັດແລ້ວ ຄິດມາຊ້າຈາກເວລາເສັດພັກ. ຂໍ້ຈຳກັດ: ລາບ່າຍ / ເປັນຊົ່ວໂມງ ບໍ່ປັບເວລາເຂົ້າ-ອອກ.
- **ພັກຊົດເຊີຍ**: ມາເຮັດວຽກວັນພັກລັດຖະການ ໄດ້ມື້ພັກຊົດເຊີຍ (ເຕັມກະ = 1 ມື້, ເຄິ່ງກະ = 0.5; ຕ່ຳກວ່ານັ້ນບໍ່ໄດ້). ໝົດອາຍຸຕາມຕັ້ງຄ່າ (ເລີ່ມຕົ້ນ 90 ມື້, 0 = ບໍ່ໝົດ), ໃຊ້ມື້ເກົ່າກ່ອນ. ນັບສະເພາະສະແກນທີ່ຢືນຢັນແລ້ວ.
- **ໂບນັດ / ຄອມມິດຊັນ / ອື່ນໆ**: ໜ້າເງິນເດືອນ → ເພີ່ມລາຍການ (ຄອມ = ຍອດຂາຍ × %). ຜ່ານການກວດ 2 ຄົນ, ງວດທີ່ລັອກແລ້ວເພີ່ມບໍ່ໄດ້, ລັອກງວດບໍ່ໄດ້ຖ້າຍັງມີລາຍການລໍອະນຸມັດ. ເລືອກໄດ້ວ່າຄິດອາກອນຫຼືບໍ່. **ເບ້ຍລ້ຽງຕໍ່ກະ** ຕັ້ງໃນ ຕັ້ງຄ່າ → ກະວຽກ ແລະ ຄິດຈາກກະທີ່ເຮັດຈິງ.
- **ຈ່າຍວັນລາພັກຄ້າງເມື່ອອອກ**: ຕອນປິດບັນຊີ ລະບົບຄິດວັນລາພັກ + ພັກຊົດເຊີຍທີ່ເຫຼືອ × ເງິນເດືອນ/26 ເປັນລາຍການ "ອື່ນໆ" (ຜ່ານການກວດ 2 ຄົນ). ເປີດ / ປິດໃນຕັ້ງຄ່າ. ⚠️ ກວດກັບກົດໝາຍແຮງງານກ່ອນໃຊ້ຈິງ.
- **ຫຼາຍບໍລິສັດ**: ໜ້າ login → ປ່ຽນບໍລິສັດ / ສ້າງໃໝ່. ແຕ່ລະບໍລິສັດມີຂໍ້ມູນ, ຕັ້ງຄ່າ ແລະ audit log ແຍກກັນ. ບໍລິສັດໃໝ່ທົດລອງ Pro 30 ວັນ ແລ້ວກັບເປັນ Free (ເກີນກຳນົດມີ 7 ວັນຜ່ອນຜັນ; ຂໍ້ມູນບໍ່ຫາຍ).
- **ແພັກເກັດ ແລະ ຟີເຈີ**: Free / Basic / Pro ກຳນົດຈຳນວນພະນັກງານ, ສາຂາ ແລະ ຟີເຈີ (Export Excel, ໂບນັດ/ຄອມ). ຜູ້ໃຫ້ບໍລິການເປີດ-ປິດຟີເຈີ ແລະ ປ່ຽນຂີດຈຳກັດສະເພາະບໍລິສັດໄດ້ ແລະ ບັນທຶກການຊຳລະດ້ວຍມື (ໜ້າ "ຈັດການບໍລິສັດ & ແພັກເກັດ"). ⚠️ ລາຄາ ແລະ ຂີດຈຳກັດເປັນຕົວຢ່າງ. ໜ້ານີ້ໃນໂໝດສາທິດບໍ່ມີ login ແລະ ຍັງບໍ່ຮັບເງິນອັດຕະໂນມັດ — ຕ້ອງມີ backend ແລະ ວິທີຮັບຊຳລະ.
- **ຜູກເຄື່ອງ / ປ່ຽນເຄື່ອງ**: ເຄື່ອງທຳອິດທີ່ສະແກນ (ຫຼື ລົງທະບຽນໃບໜ້າ) ຖືກຜູກກັບບັນຊີ. ສະແກນຈາກເຄື່ອງອື່ນ → ລໍຫົວໜ້າກວດ. ປ່ຽນໂທລະສັບ: ສົ່ງຄຳຂໍຈາກເຄື່ອງໃໝ່ (ຕັ້ງຄ່າ → ເຄື່ອງທີ່ຜູກ) ເຈົ້າຂອງອະນຸມັດ ແລ້ວລົງທະບຽນໃບໜ້າໃໝ່; ເຈົ້າຂອງ / ບັນຊີລ້າງເຄື່ອງທີ່ຜູກໄດ້ຈາກໜ້າພະນັກງານ. ຍັງບໍ່ມີ "ລະຫັດຜ່ານ" ເພາະຍັງບໍ່ມີລະບົບ login ຈິງ.
- **ໜ້າລົງເວລາ**: ເທິງສຸດເປັນບັດຮູບໂປຟາຍ + ຊື່ + ເວລາ. ແຖວ GPS ກົດເພື່ອເປີດແຜນທີ່ (ແລະ ເລືອກສາຂາເອງ) ຂ້າງໃນ. ເພີ່ມ / ປ່ຽນ / ລຶບຮູບໂປຟາຍໄດ້ໃນໜ້າ ໂປຣໄຟລ໌ (ຕັດເປັນຮູບສີ່ຫຼ່ຽມ 256px).
- **ໄອຄອນສອງໂທນ** (ແນວ Dribbble "HomeMedix Icon Set"): ເສັ້ນຂອບມົນ ໜາ 2px + ຈຸດເດັ່ນສີສົດ ໃນເມນູ, ແຖບເທິງ, ແຖວ GPS ແລະ ເມນູໜ້າບໍລິຫານ (src/ui/Icon.tsx). ສີຫຼັກຂອງແອັບຍັງເປັນສີຂຽວຟ້າ (teal) ເໝືອນເດີມ.
- **ໜ້າຕາແບບແອັບສຸຂະພາບ (ສີເດີມ)**: ຫົວແອັບເປັນສີຂຽວຟ້າໄລ່ສີ ມີປຸ່ມກົມໂປ່ງແສງ, ຄຳທັກທາຍຕາມຊົ່ວໂມງ, ແຖບ ລົງເວລາ/ປະຕິທິນ/ລາ ເປັນປຸ່ມແຄບສູດ (pill), ບັດພະນັກງານ (ຮູບເຕັມບັດ, ຊື່ + ຕຳແໜ່ງ + ພະແນກ · ສາຂາ, ນາຬິກາຢູ່ມຸມລຸ່ມຂວາ), ປຸ່ມ/ບັດມົນຂຶ້ນ ແລະ ວົງແຫວນອ່ອນຮອບໜ້າຕອນສະແກນ. ການໃຊ້ງານ (ຕຳແໜ່ງປຸ່ມ ແລະ ຂັ້ນຕອນ) ຍັງເໝືອນເດີມ.
- **ແຖບຫຼັກຢູ່ລຸ່ມ**: ລົງເວລາ / ປະຕິທິນ / ລາ ເປັນແຖບລອຍຢູ່ລຸ່ມຈໍ ກົດງ່າຍດ້ວຍນິ້ວໂປ້ (ເຫັນສະເພາະ 3 ໜ້າຫຼັກ).
- **ປະຕິທິນ: ກົດວັນທີ ແລ້ວເຮັດໄດ້ເລີຍ**: ກົດມື້ໃດກໍໄດ້ ຈະເຫັນເວລາເຂົ້າ-ອອກຂອງມື້ນັ້ນ ແລະ ລາຍການ "ເຮັດຫຍັງໄດ້ໃນມື້ນີ້": ມື້ຕໍ່ໄປ → ຂໍລາ (ມື້ນັ້ນໃສ່ໃຫ້ແລ້ວ) / ຍົກເລີກການລາ / ສະລັບກະ (ຫຼື ມາເຮັດວຽກແທນວັນພັກ ຖ້າເປັນວັນພັກ) / ປ່ຽນຕາຕະລາງວຽກ; ມື້ທີ່ຜ່ານມາ → ຂໍແກ້ເວລາເຂົ້າ-ອອກ / ຂໍ OT. ວັນພັກລັດຖະການບໍ່ມີຂໍລາ. ກົດເກນຢູ່ src/domain/dayActions.ts; ແບບຟອມຍັງກວດເງື່ອນໄຂເໝືອນເດີມ.
- **ແອນິເມຊັນການກົດ** (ແນວວິດີໂອຕົວຢ່າງ): ກົດແລ້ວປຸ່ມຫົດນຸ້ມລົງແລ້ວເດັ້ງກັບ (spring) + ມີວົງຄື້ນແຜ່ອອກຈາກຈຸດທີ່ນິ້ວແຕະ ແລະ ສັ່ນເບົາໆໃນມືຖືທີ່ຮອງຮັບ; ກົດວັນໃນປະຕິທິນວົງກົມເດັ້ງຂຶ້ນ ແລະ ເນື້ອຫາຂອງມື້ນັ້ນໂຜ່ຂຶ້ນທີລະອັນ; ກົດເຂົ້າວຽກ/ອອກວຽກ ໜ້າສະແກນຂະຫຍາຍອອກຈາກຈຸດທີ່ກົດ; ແຜ່ນແບບຟອມເລື່ອນຂຶ້ນຈາກລຸ່ມ ແລະ ເລື່ອນລົງຕອນປິດ, ເມນູເລື່ອນເຂົ້າ-ອອກທາງຊ້າຍ, ໜ້າສະແກນ/ຜົນລັບ/ສະລິບຄ່ອຍໆຈາງຫາຍຕອນປິດ, ໜ້າຜົນລັບເດັ້ງວົງຕິກ (src/ui/closing.ts). ປິດໄດ້ອັດຕະໂນມັດຖ້າໂທລະສັບຕັ້ງ "ຫຼຸດການເຄື່ອນໄຫວ" (prefers-reduced-motion). ໂຄ້ດ: src/ui/press.ts + ທ້າຍ src/styles.css.
- **ໃບໜ້າ 3 ທ່າ + ຂໍຖ່າຍໃໝ່**: ລົງທະບຽນໃບໜ້າ 3 ທ່າ (ມອງຕົງ, ຫັນເລັກນ້ອຍທາງຊ້າຍ ແລະ ທາງຂວາ — ກວດມຸມໜ້າຈາກ landmarks) ຕອນສະແກນປຽບທຽບກັບທຸກທ່າ ແລ້ວເອົາຄະແນນທີ່ດີສຸດ; ທ່າຂ້າງທີ່ຖ່າຍບໍ່ໄດ້ຖືກຂ້າມ (ມອງຕົງຕ້ອງໄດ້). ເມື່ອໜ້າປ່ຽນ (ຈ່ອຍ/ຕຸ້ຍ/ແວ່ນ/ໜວດ) ພະນັກງານກົດ ຕັ້ງຄ່າ → ຂໍລົງທະບຽນໃບໜ້າໃໝ່ → ຫົວໜ້າ (ໃນພະແນກ) ຫຼື ເຈົ້າຂອງອະນຸມັດ → ການກົດເຂົ້າວຽກເທື່ອຕໍ່ໄປຖ່າຍໃໝ່ 3 ທ່າ; ໃບໜ້າເກົ່າໃຊ້ໄດ້ຈົນກວ່າຈະຖ່າຍໃໝ່. ຄົນທີ່ລົງທະບຽນໄວ້ແບບເກົ່າ (ທ່າດຽວ) ຍັງໃຊ້ໄດ້ ແລະ ຂໍຖ່າຍເພີ່ມໄດ້.
- **ສະແກນໜ້າໃນບ່ອນມືດ / ໄກ / ເບລອ**: ກ່ອນຫາໃບໜ້າ ລະບົບເຮັດໃຫ້ພາບທີ່ມືດສະຫວ່າງຂຶ້ນເອງ ແລະ ລອງຕົວກວດຈັບທີ່ໄວຂຶ້ນຖ້າຕົວທຳອິດຫາບໍ່ເຫັນ. ຖ້າຍັງຫາບໍ່ເຫັນ ຈະບອກເຫດຜົນເປັນພາສາລາວ (ມືດໄປ / ແສງຈ້າ / ເບລອ / ໄກເກີນ / ມອງຕົງ ແລະ ເອົາແວ່ນດຳອອກ) ທັງຕອນສະແກນ ແລະ ຕອນລົງທະບຽນ. ວັດກັບໃບໜ້າຈິງ 12 ຄົນ ໃນ 12 ສະພາບ: ຫາໃບໜ້າເຈີ 52% → 78%. ⚠️ ຄົນອື່ນສະແກນຜ່ານເກນ 70% ຍັງເກີດໄດ້ບາງຄູ່ ແລະ ຍັງບໍ່ໄດ້ທົດສອບກັບກ້ອງມືຖືຈິງ.

## ກົດທີ່ລະບົບບັງຄັບ (ສຳລັບການກວດສອບ)

- ສະແກນບໍ່ຜ່ານ (ໜ້າ / GPS / ໂມງຕ່າງ > 2 ນທ) → ບັນທຶກເປັນ "ລໍກວດ", ບໍ່ບລັອກພະນັກງານ
- ຫ້າມອະນຸມັດ ຫຼື ກວດລາຍການຂອງຕົນເອງ; ປະຕິເສດຕ້ອງມີເຫດຜົນ
- ເງິນເດືອນ / ເລກບັນຊີ / ລັອກງວດ: ກວດ 2 ຄົນ (ປິດໄດ້ໃນຕັ້ງຄ່າ)
- ງວດທີ່ລັອກແລ້ວແກ້ບໍ່ໄດ້; audit log ເພີ່ມໄດ້ຢ່າງດຽວ
- ສຸ່ມກວດຮູບສະແກນມື້ລະ N ຮູບ (seed ຕາມວັນທີ — ຜູ້ກວດສອບສຸ່ມຊ້ຳໄດ້ຜົນເກົ່າ)

⚠️ ອັດຕາອາກອນ, ປະກັນສັງຄົມ ແລະ OT ໃນ `src/domain/defaults.ts` ເປັນ**ຕົວຢ່າງ** — ກວດກັບກົດໝາຍປັດຈຸບັນກ່ອນໃຊ້ຈິງ.

## ເລີ່ມໃຊ້ຈິງ (ຂໍ້ມູນຢູ່ໃນເບົາເຊີຂອງເຄື່ອງນີ້)

1. ໜ້າເຂົ້າລະບົບ → ບໍລິສັດ "ປ່ຽນ ›" → **+ ສ້າງບໍລິສັດໃໝ່** → ໃສ່ຊື່ບໍລິສັດ, ຊື່ເຈົ້າຂອງ ແລະ **PIN ເຈົ້າຂອງ** (ໄດ້ທົດລອງ Pro 30 ມື້). ເຈົ້າຂອງເຂົ້າລະບົບດ້ວຍລະຫັດ **ST-001** + PIN.
2. ເຂົ້າເປັນເຈົ້າຂອງ (ໃນຄອມຈະເຂົ້າໜ້າບໍລິຫານເລີຍ) → **ກົດເກນ & ຕັ້ງຄ່າ**: ຕັ້ງສາຂາ (ຢືນຢູ່ຮ້ານແລ້ວກົດ "ໃຊ້ຕຳແໜ່ງຂ້ອຍຕອນນີ້"), ກະວຽກ, ວັນພັກລັດຖະການ.
3. **ພະນັກງານ → ⬆ ນຳເຂົ້າຈາກ Excel** → ດາວໂຫຼດແບບຟອມ → ໃສ່ລາຍຊື່ → ເລືອກໄຟລ໌ → ກວດຕາຕະລາງ (ແຖວຜິດເປັນສີແດງ ບອກເຫດຜົນ) → ນຳເຂົ້າ.
   ຖ້າເປີດ "ກວດ 2 ຄົນ": ການຈ້າງຈະລໍອີກຄົນ (ເຈົ້າຂອງ / ບັນຊີ ທີ່ບໍ່ແມ່ນຄົນນຳເຂົ້າ) ກົດ **ອະນຸມັດການຈ້າງທັງໝົດ**. ຖ້າມີເຈົ້າຂອງຄົນດຽວ ໃຫ້ປິດ "ກວດ 2 ຄົນ" ຊົ່ວຄາວຕອນຕັ້ງລະບົບ (ມີບັນທຶກໃນ Audit log) ແລ້ວເປີດຄືນ.
4. **ສິດ & ການອະນຸມັດ** (ເຈົ້າຂອງ): ກຳນົດບົດບາດຂອງແຕ່ລະຄົນ (ຫົວໜ້າ + ພະແນກທີ່ດູແລ, ບັນຊີ, ເຈົ້າຂອງ, ຜູ້ກວດສອບ) · **ອອກ PIN ໃຫ້ຄົນທີ່ຍັງບໍ່ມີ** (PIN ຊົ່ວຄາວ 6 ຕົວ ສະແດງເທື່ອດຽວ ພິມໄດ້; ເຂົ້າເທື່ອທຳອິດຕ້ອງຕັ້ງ PIN ເອງ) · ຕາຕະລາງ **ໃຜອະນຸມັດຫຍັງ** (ຫົວໜ້າ / ບັນຊີ ຕໍ່ເລື່ອງ; ເຈົ້າຂອງອະນຸມັດໄດ້ສະເໝີ; ຜູ້ກວດສອບ ແລະ ພະນັກງານອະນຸມັດບໍ່ໄດ້) · **ເປີດ/ປິດເມນູຂອງພະນັກງານ** ທີ່ບໍລິສັດບໍ່ໃຊ້.
5. **ກົດເກນ & ຕັ້ງຄ່າ → ສຳຮອງຂໍ້ມູນ**: ດາວໂຫຼດໄຟລ໌ສຳຮອງເປັນປະຈຳ. ຂໍ້ມູນຢູ່ແຕ່ໃນເບົາເຊີນີ້ — ລ້າງເບົາເຊີ / ເຄື່ອງເສຍ = ຂໍ້ມູນຫາຍ ຖ້າບໍ່ມີໄຟລ໌ສຳຮອງ. ກູ້ຄືນໃນເຄື່ອງໃໝ່ດ້ວຍໄຟລ໌ນັ້ນ.

**ເຂົ້າລະບົບ**: ບໍລິສັດຈິງເຂົ້າດ້ວຍ ລະຫັດພະນັກງານ + PIN (ເກັບແຕ່ hash; ໃສ່ຜິດ 5 ເທື່ອ ລັອກ 5 ນາທີ; ບໍ່ມີໃຜແຕະເຄື່ອງ 3 ນາທີ (ຄອມ 15 ນາທີ) ອອກເອງ). ປ່ຽນ PIN ເອງໃນ ຕັ້ງຄ່າ. ບໍລິສັດສາທິດຍັງເລືອກຜູ້ໃຊ້ໄດ້ເລີຍ ເພື່ອລອງແຕ່ລະບົດບາດ. ບໍລິສັດທີ່ສ້າງກ່ອນມີ PIN: ໜ້າເຂົ້າລະບົບຈະໃຫ້ເຈົ້າຂອງຕັ້ງ PIN ເທື່ອທຳອິດ.

⚠️ ຂໍ້ຈຳກັດຂອງການເກັບໃນເບົາເຊີ: ທຸກຄົນຕ້ອງໃຊ້ **ເຄື່ອງດຽວກັນ** (ເຊັ່ນ ແທັບເລັດຢູ່ຮ້ານ) — ໂທລະສັບແຕ່ລະຄົນຈະບໍ່ເຫັນຂໍ້ມູນກັນ. PIN ກັນບໍ່ໃຫ້ເຂົ້າບັນຊີຄົນອື່ນໃນເຄື່ອງດຽວກັນ ແຕ່ບໍ່ແມ່ນຄວາມປອດໄພລະດັບທະນາຄານ (ຂໍ້ມູນຢູ່ໃນເບົາເຊີ). ໜ້າ "ຈັດການບໍລິສັດ & ແພັກເກັດ" ຍັງບໍ່ມີລະຫັດ. ບໍລິສັດໃໝ່ຫຼັງທົດລອງ 30 ມື້ ກັບເປັນ Free (ສູງສຸດ 5 ຄົນ) — ຕັ້ງແພັກເກັດໄດ້ທີ່ "ຈັດການບໍລິສັດ & ແພັກເກັດ".

## ເວລາເຂົ້າ-ອອກ ແລະ ການກວດ 2 ຄົນ

- **ເວລາສະເພາະຄົນ**: ພະນັກງານ → ແກ້ໄຂ → "ກະປະຈຳ / ເວລາເຂົ້າ-ອອກ" → ເລືອກ **"ກຳນົດເວລາສະເພາະຄົນນີ້…"** ໃສ່ ເຂົ້າ / ອອກ / ເວລາພັກ (ອອກກາຍທ່ຽງຄືນໄດ້, ຫຼື ຢືດຢຸ່ນ). ຄິດມາຊ້າ, OT ແລະ ລືມລົງເວລາອອກ ໃຊ້ເວລານີ້; ບໍ່ປາກົດໃນລາຍການກະທີ່ໃຊ້ຮ່ວມກັນ.
- **ເວລາຂອງທັງອົງກອນ / ພະແນກ**: ແກ້ເວລາຂອງກະໃນ ກົດເກນ & ຕັ້ງຄ່າ → ກະວຽກ (ທຸກຄົນໃນກະນັ້ນປ່ຽນຕາມ), ຫຼື ພະນັກງານ → **🕘 ຕັ້ງເວລາເຂົ້າ-ອອກໃຫ້ຫຼາຍຄົນ** ເລືອກທຸກຄົນ ຫຼື ພະແນກ + ກະ (+ ວັນພັກປະຈຳອາທິດ).
- **ບໍ່ຕ້ອງມີຄົນອະນຸມັດ**: ສິດ & ການອະນຸມັດ → ປິດ "ກວດ 2 ຄົນ" ສຳລັບ ການຈ້າງ / ປິດບັນຊີ / ເງິນເດືອນ / ເລກບັນຊີ — ແລ້ວຄົນທີ່ແກ້ໄຂບັນທຶກໄດ້ເລີຍ. ຄຳຂໍທີ່ຄ້າງຢູ່ ກົດ **"ນຳໃຊ້ເລີຍ"**. ໃນຮ້ານທີ່ມີເຈົ້າຂອງຄົນດຽວ ຈະມີປຸ່ມ "ປິດການກວດ 2 ຄົນ" ໃຫ້ເລີຍ. ທຸກການປ່ຽນຍັງມີ Audit log. ການລາ / OT / ແກ້ເວລາ ຕັ້ງຜູ້ອະນຸມັດໃນຕາຕະລາງ "ໃຜອະນຸມັດຫຍັງ" (ເຈົ້າຂອງອະນຸມັດໄດ້ສະເໝີ).
- **ລຶບກະ**: ກົດເກນ & ຕັ້ງຄ່າ → ກະວຽກ → ປຸ່ມ **🗑 ລຶບ** ທ້າຍແຖວ (ແຖວທີ່ຍັງບໍ່ບັນທຶກ ລຶບໄດ້ເລີຍ). ລຶບບໍ່ໄດ້ຖ້າຍັງມີຄົນໃຊ້ກະນັ້ນ, ມີການປ່ຽນຕາຕະລາງ ຫຼື ຄຳຂໍທີ່ລໍອະນຸມັດໃຊ້ກະນັ້ນ, ຫຼື ເປັນກະສຸດທ້າຍ — ລະບົບບອກເຫດຜົນ. ການລຶບມີໃນ Audit log ແລະ ປະຫວັດການແກ້ກົດເກນ.

## ເຈົ້າຂອງ (Admin) ເຫັນ ແລະ ກຳນົດໄດ້ທຸກຢ່າງ

- **ອະນຸມັດເລື່ອງຂອງຕົນເອງ**: ເຈົ້າຂອງອະນຸມັດຄຳຂໍຂອງຕົນເອງໄດ້ (ລາ, OT, ແກ້ເວລາ, ເບີກເງິນ, ກວດສະແກນ, ເງິນເດືອນ, ລາຍການຈ່າຍ, ປິດງວດ) ເມື່ອ **ປິດ "ກວດ 2 ຄົນ"** ຫຼື ເມື່ອ**ບໍ່ມີຜູ້ຈັດການຄົນອື່ນ** ທີ່ອະນຸມັດແທນໄດ້ (ຮ້ານເຈົ້າຂອງຄົນດຽວ). ຕ້ອງການຜູ້ອະນຸມັດ 2 ຄົນກໍນັບ 1 ເມື່ອເປັນເລື່ອງຂອງເຈົ້າຂອງເອງ. ຄົນອື່ນ (ຫົວໜ້າ, ບັນຊີ) ຍັງອະນຸມັດຂອງຕົນເອງບໍ່ໄດ້. ມີບັນທຶກໃນ Audit log (ຊື່ເຈົ້າຂອງຢູ່ຄູ່ກັບຄຳຂໍຂອງຕົນເອງ).
- **ແກ້ຂໍ້ມູນພະນັກງານໄດ້ທຸກຊ່ອງ**: ພະນັກງານ → ແກ້ໄຂ: ຊື່, ລະຫັດ, ພະແນກ, ຕຳແໜ່ງ, ສາຂາຫຼັກ, ວັນເລີ່ມວຽກ (ບັນທຶກທັນທີ), ເງິນອຸດໜູນ + ວິທີຮັບເງິນ/ທະນາຄານ + ເງິນເດືອນ + ເລກບັນຊີ (ຕາມກົດ "ກວດ 2 ຄົນ"), ກະ/ເວລາ, ວັນພັກ, ບົດບາດ.
- **ສາຂາ**: ກົດເກນ & ຕັ້ງຄ່າ → ສາຂາ & GPS: ແກ້ຊື່ / ພິກັດ, ລັດສະໝີ, ເພີ່ມ, **ລຶບ** (ລຶບໄດ້ຖ້າບໍ່ມີຄົນຕັ້ງເປັນສາຂາຫຼັກ ແລະ ບໍ່ມີປະຫວັດການລົງເວລາ).
- **ເມນູທີ່ປິດໃຫ້ພະນັກງານ**: ເຈົ້າຂອງຍັງເຫັນຢູ່ສະເໝີ.
- ເຈົ້າຂອງເຂົ້າໄດ້ທຸກໜ້າ: ພາບລວມ, ກວດສະແກນ, ອະນຸມັດ, ລາ/ເບີກ, ພະນັກງານ, ເງິນເດືອນ, ສິດ & ການອະນຸມັດ, ກົດເກນ & ຕັ້ງຄ່າ, Audit log. ສິ່ງທີ່ເຈົ້າຂອງຍັງ**ແກ້ບໍ່ໄດ້ໂດຍເຈດຕະນາ**: ບົດບາດຂອງຕົນເອງ (ກັນລັອກຕົນເອງ) ແລະ ເຈົ້າຂອງຄົນສຸດທ້າຍລົບບົດບາດບໍ່ໄດ້; ງວດເງິນເດືອນທີ່ລັອກແລ້ວ (ແກ້ເປັນລາຍການປັບໃນເດືອນຕໍ່ໄປ).

## ໂໝດອອນລາຍ (ມືຖືແຕ່ລະຄົນ ໃຊ້ຖານຂໍ້ມູນດຽວກັນ)
ໂໝດປົກກະຕິເກັບຂໍ້ມູນໃນເບົາເຊີຂອງເຄື່ອງທີ່ສ້າງບໍລິສັດ ຈຶ່ງໃຫ້ພະນັກງານເຂົ້າຈາກມືຖືຂອງຕົນບໍ່ໄດ້. ໂໝດອອນລາຍໃຊ້ Supabase (ແຜນຟຣີ) ເປັນຖານຂໍ້ມູນກາງ — ແອັບຍັງຢູ່ GitHub Pages ຄືເກົ່າ.
- ຕັ້ງຄັ້ງດຽວຕາມ [supabase/README.md](supabase/README.md), ແລ້ວກົດ **🌐 ເຂົ້າບໍລິສັດອອນລາຍ** ໃນແອັບ.
- ເຂົ້າດ້ວຍ ລະຫັດພະນັກງານ + PIN 6 ຕົວ; ເຈົ້າຂອງສົ່ງ **ລິ້ງຕັ້ງຄ່າມືຖື** (ໜ້າ ສິດ & ການອະນຸມັດ) ໃຫ້ພະນັກງານ.
- ຖານຂໍ້ມູນບັງຄັບສິດເອງ (RLS): ເງິນເດືອນ/ໃບໜ້າ/ສະລິບ ເຫັນສະເພາະຄົນທີ່ກ່ຽວຂ້ອງ; ກົດເນື້ອໃນຍັງກວດທີ່ແອັບ (ເບິ່ງຂໍ້ຈຳກັດໃນ supabase/README.md).
- ສະແກນຕອນບໍ່ມີສັນຍານ ເກັບໄວ້ໃນມືຖືແລ້ວສົ່ງຕອນມີສັນຍານ.

### ເກັບໃນ Google Sheet ແທນ Supabase
ບໍ່ຢາກສ້າງ Supabase? ໃຊ້ Google Sheet + Apps Script ກໍໄດ້ — ຕັ້ງຕາມ [apps-script/README.md](apps-script/README.md) ແລ້ວເລືອກແຖບ **Google Sheet** ໃນໜ້າ 🌐 ເຂົ້າບໍລິສັດອອນລາຍ. ສິດຂອງແຕ່ລະບົດບາດຄືກັນ; ຊ້າກວ່າ ແລະ ເໝາະກັບບໍລິສັດນ້ອຍ.
