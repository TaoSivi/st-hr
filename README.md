# ST HR — ລະບົບບຸກຄະລາກອນ

ແອັບ HR ແຍກຈາກ ST POS: ສະແກນໜ້າ + GPS ລົງເວລາ, ລາພັກ, ເບີກລ່ວງໜ້າ, ເງິນເດືອນ, audit log.
ຕອນນີ້ເປັນ **ໂໝດສາທິດ**: ຂໍ້ມູນເກັບໃນ browser ຂອງເຄື່ອງທີ່ເປີດເທົ່ານັ້ນ (localStorage).

## ແລ່ນໃນເຄື່ອງ

```bash
npm install
npm run dev      # http://localhost:5173
npm test         # ທົດສອບໂຕຄິດໄລ່ເງິນເດືອນ, ມາຊ້າ, ລາພັກ, ການອະນຸມັດ
npm run build    # ໄດ້ໂຟນເດີ dist/
```

ກ້ອງ ແລະ GPS ຕ້ອງໃຊ້ HTTPS (ຫຼື localhost). ລອງໃນມືຖືແທ້ຜ່ານລິ້ງ GitHub Pages.

## ລອງແຕ່ລະບົດບາດ

ໜ້າທຳອິດເລືອກ "ເຂົ້າໃຊ້ເປັນ":

| ຜູ້ໃຊ້ | ບົດບາດ | ລອງຫຍັງ |
|---|---|---|
| ຄຳຫຼ້າ, ບຸນມີ, … | ພະນັກງານ | ລົງທະບຽນໜ້າ → ກົດປຸ່ມໃຫຍ່ → ສະແກນ; ຂໍລາ; ເບີກເງິນ |
| ສົມພອນ | ຫົວໜ້າ | ກວດການລົງເວລາ "ລໍກວດ", ອະນຸມັດລາ, ສັ່ງ OT |
| ແສງດາວ | ບັນຊີ | ກະກຽມເງິນເດືອນ, Export |
| Admin | ເຈົ້າຂອງ / HR | ອະນຸມັດ & ລັອກງວດ, ຕັ້ງຄ່າ, Audit log |

ຕັ້ງຄ່າ → ສາຂາ → **"ໃຊ້ຕຳແໜ່ງຂ້ອຍຕອນນີ້"** ເພື່ອໃຫ້ GPS ຜ່ານຕອນທົດລອງ.

## ໂຄງສ້າງ

```
src/domain/   ກົດລະບຽບທຸລະກິດ (pure functions + tests) — ບໍ່ຂຶ້ນກັບ UI ຫຼື storage
src/data/     DataStore: LocalStore (ສາທິດ) / ApiStore (server ຈິງ, ໃຊ້ interface ດຽວກັນ)
src/device/   ກ້ອງ + ຈື່ໜ້າ (@vladmandic/face-api, models ຢູ່ public/models), GPS
src/ui/       ໜ້າຈໍພະນັກງານ (ມືຖື) ແລະ ໜ້າຈໍຫົວໜ້າ / HR
```

## Export ລາຍງານເຂົ້າ-ອອກ (Excel)

ໜ້າ **ລາຍງານ** (ພະນັກງານ) ແລະ **ລາຍງານທີມ** (ຫົວໜ້າ/ບັນຊີ/ເຈົ້າຂອງ/ຜູ້ກວດສອບ) ມີປຸ່ມດາວໂຫຼດ .xlsx 3 sheet: ສະຫຼຸບ, ລາຍລະອຽດລາຍມື້, ຂໍ້ມູນລາຍງານ. ຕົວເລກໃນໜ້າຈໍ ແລະ ໄຟລ໌ມາຈາກຕົວຄິດດຽວກັນ. ຫົວໜ້າໄດ້ສະເພາະພະແນກທີ່ດູແລ. ທຸກການ export ຖືກບັນທຶກໃນ audit log.

## ການຈັດການພະນັກງານ, ກະ ແລະ ເງິນເດືອນ

- **ເພີ່ມ / ປິດບັນຊີພະນັກງານ** (ພະນັກງານ → "+ ເພີ່ມພະນັກງານ" ແລະ ແກ້ໄຂ → ລາອອກ): ໃຊ້ການກວດ 2 ຄົນຄືກັບເງິນເດືອນ. ບົດບາດເລີ່ມເປັນ "ພະນັກງານ" ສະເໝີ. ເດືອນທີ່ເຂົ້າ / ອອກ ຄິດເງິນເດືອນຕາມສັດສ່ວນວັນ (OT ແລະ ລາບໍ່ຮັບເງິນໃຊ້ເງິນເດືອນເຕັມຄິດອັດຕາ). ຄົນທີ່ອອກແລ້ວບໍ່ຢູ່ໃນລາຍຊື່ login, ເງິນເດືອນ ແລະ ລາຍງານຂອງເດືອນຖັດໄປ; ປະຫວັດຍັງຢູ່ຄົບ.
- **ເພີ່ມສາຂາ** (ຕັ້ງຄ່າ → ສາຂາ & GPS): ກວດພິກັດ ແລະ ລັດສະໝີ 10–2000 ມ. ຍັງບໍ່ມີການລຶບສາຂາ (ກັນສະແກນເກົ່າຊີ້ໄປຫາສາຂາທີ່ບໍ່ມີ).
- **ສະລິບເງິນເດືອນ**: ພະນັກງານພິມ / ບັນທຶກ PDF ໄດ້ເອງ; ບັນຊີ / ເຈົ້າຂອງ ເປີດສະລິບຂອງແຕ່ລະຄົນຈາກໜ້າເງິນເດືອນ. ງວດທີ່ຍັງບໍ່ລັອກຖືກໝາຍວ່າ "ຕົວເລກປະມານການ". **Export Excel** ຂອງງວດ (ແຕ່ລະຄົນ + ແຖວລວມ + sheet ຂໍ້ມູນງວດ) ຖືກບັນທຶກໃນ audit log.
- **ລືມລົງເວລາອອກ**: ເຂົ້າແລ້ວແຕ່ບໍ່ອອກ ຫຼັງກະເລີກ + 60 ນທ → ໝາຍ "ລືມລົງເວລາອອກ" ໃນລາຍງານ (ມີຖັນນັບມື້), ແຈ້ງເຕືອນພະນັກງານ ແລະ ຫົວໜ້າພະແນກ (ຄັ້ງດຽວຕໍ່ຄົນຕໍ່ມື້), ແລະ ມີແຖບໃນໜ້າລົງເວລາໃຫ້ກົດຂໍແກ້ເວລາອອກ. ຍ້ອນຫຼັງ 7 ມື້.
- **ກະຂ້າມຄືນ**: ກະທີ່ເວລາເລີກນ້ອຍກວ່າເວລາເລີ່ມ (22:00 → 06:00, ຍາວສຸດ 16 ຊມ.). ການລົງເວລາຫຼັງທ່ຽງຄືນນັບເປັນມື້ທີ່ເລີ່ມກະ. ອອກວຽກຊ້າກວ່າກະເລີກໄດ້ເຖິງ 4 ຊມ. (OT); ຫຼັງນັ້ນຕ້ອງຂໍແກ້ເວລາ. ຂໍ້ຈຳກັດ: ຖ້າເຂົ້າວຽກກະກາງຄືນຫຼັງທ່ຽງຄືນ ລະບົບນັບເປັນມື້ໃໝ່.

- **ລາເຄິ່ງວັນ / ເປັນຊົ່ວໂມງ**: ເລືອກເຄິ່ງວັນເຊົ້າ / ບ່າຍ ຫຼື ຈຳນວນຊົ່ວໂມງ (ເຄິ່ງຊົ່ວໂມງເປັນຂັ້ນ) ໃນມື້ດຽວ. ນັບເປັນມື້ຕາມຊົ່ວໂມງເຮັດວຽກຂອງກະຕົນເອງ (7.5 ຊມ → 3 ຊມ = 0.4 ມື້). ກວດການລາທັບຊ້ອນ ແລະ ລາລວມບໍ່ເກີນ 1 ມື້. ລາເຊົ້າທີ່ອະນຸມັດແລ້ວ ຄິດມາຊ້າຈາກເວລາເສັດພັກ. ຂໍ້ຈຳກັດ: ລາບ່າຍ / ເປັນຊົ່ວໂມງ ບໍ່ປັບເວລາເຂົ້າ-ອອກ.
- **ພັກຊົດເຊີຍ**: ມາເຮັດວຽກວັນພັກລັດຖະການ ໄດ້ມື້ພັກຊົດເຊີຍ (ເຕັມກະ = 1 ມື້, ເຄິ່ງກະ = 0.5; ຕ່ຳກວ່ານັ້ນບໍ່ໄດ້). ໝົດອາຍຸຕາມຕັ້ງຄ່າ (ເລີ່ມຕົ້ນ 90 ມື້, 0 = ບໍ່ໝົດ), ໃຊ້ມື້ເກົ່າກ່ອນ. ນັບສະເພາະສະແກນທີ່ຢືນຢັນແລ້ວ.
- **ໂບນັດ / ຄອມມິດຊັນ / ອື່ນໆ**: ໜ້າເງິນເດືອນ → ເພີ່ມລາຍການ (ຄອມ = ຍອດຂາຍ × %). ຜ່ານການກວດ 2 ຄົນ, ງວດທີ່ລັອກແລ້ວເພີ່ມບໍ່ໄດ້, ລັອກງວດບໍ່ໄດ້ຖ້າຍັງມີລາຍການລໍອະນຸມັດ. ເລືອກໄດ້ວ່າຄິດອາກອນຫຼືບໍ່. **ເບ້ຍລ້ຽງຕໍ່ກະ** ຕັ້ງໃນ ຕັ້ງຄ່າ → ກະວຽກ ແລະ ຄິດຈາກກະທີ່ເຮັດຈິງ.
- **ຈ່າຍວັນລາພັກຄ້າງເມື່ອອອກ**: ຕອນປິດບັນຊີ ລະບົບຄິດວັນລາພັກ + ພັກຊົດເຊີຍທີ່ເຫຼືອ × ເງິນເດືອນ/26 ເປັນລາຍການ "ອື່ນໆ" (ຜ່ານການກວດ 2 ຄົນ). ເປີດ / ປິດໃນຕັ້ງຄ່າ. ⚠️ ກວດກັບກົດໝາຍແຮງງານກ່ອນໃຊ້ຈິງ.
- **ຫຼາຍບໍລິສັດ**: ໜ້າ login → ປ່ຽນບໍລິສັດ / ສ້າງໃໝ່. ແຕ່ລະບໍລິສັດມີຂໍ້ມູນ, ຕັ້ງຄ່າ ແລະ audit log ແຍກກັນ. ບໍລິສັດໃໝ່ທົດລອງ Pro 30 ວັນ ແລ້ວກັບເປັນ Free (ເກີນກຳນົດມີ 7 ວັນຜ່ອນຜັນ; ຂໍ້ມູນບໍ່ຫາຍ).
- **ແພັກເກັດ ແລະ ຟີເຈີ**: Free / Basic / Pro ກຳນົດຈຳນວນພະນັກງານ, ສາຂາ ແລະ ຟີເຈີ (Export Excel, ໂບນັດ/ຄອມ). ຜູ້ໃຫ້ບໍລິການເປີດ-ປິດຟີເຈີ ແລະ ປ່ຽນຂີດຈຳກັດສະເພາະບໍລິສັດໄດ້ ແລະ ບັນທຶກການຊຳລະດ້ວຍມື (ໜ້າ "ຈັດການບໍລິສັດ & ແພັກເກັດ"). ⚠️ ລາຄາ ແລະ ຂີດຈຳກັດເປັນຕົວຢ່າງ. ໜ້ານີ້ໃນໂໝດສາທິດບໍ່ມີ login ແລະ ຍັງບໍ່ຮັບເງິນອັດຕະໂນມັດ — ຕ້ອງມີ backend ແລະ ວິທີຮັບຊຳລະ.
- **ຜູກເຄື່ອງ / ປ່ຽນເຄື່ອງ**: ເຄື່ອງທຳອິດທີ່ສະແກນ (ຫຼື ລົງທະບຽນໃບໜ້າ) ຖືກຜູກກັບບັນຊີ. ສະແກນຈາກເຄື່ອງອື່ນ → ລໍຫົວໜ້າກວດ. ປ່ຽນໂທລະສັບ: ສົ່ງຄຳຂໍຈາກເຄື່ອງໃໝ່ (ຕັ້ງຄ່າ → ເຄື່ອງທີ່ຜູກ) ເຈົ້າຂອງອະນຸມັດ ແລ້ວລົງທະບຽນໃບໜ້າໃໝ່; ເຈົ້າຂອງ / ບັນຊີລ້າງເຄື່ອງທີ່ຜູກໄດ້ຈາກໜ້າພະນັກງານ. ຍັງບໍ່ມີ "ລະຫັດຜ່ານ" ເພາະຍັງບໍ່ມີລະບົບ login ຈິງ.

## ກົດທີ່ລະບົບບັງຄັບ (ສຳລັບການກວດສອບ)

- ສະແກນບໍ່ຜ່ານ (ໜ້າ / GPS / ໂມງຕ່າງ > 2 ນທ) → ບັນທຶກເປັນ "ລໍກວດ", ບໍ່ບລັອກພະນັກງານ
- ຫ້າມອະນຸມັດ ຫຼື ກວດລາຍການຂອງຕົນເອງ; ປະຕິເສດຕ້ອງມີເຫດຜົນ
- ເງິນເດືອນ / ເລກບັນຊີ / ລັອກງວດ: ກວດ 2 ຄົນ (ປິດໄດ້ໃນຕັ້ງຄ່າ)
- ງວດທີ່ລັອກແລ້ວແກ້ບໍ່ໄດ້; audit log ເພີ່ມໄດ້ຢ່າງດຽວ
